# Bizarre Bazaar
A first-person supermarket simulation game where players take the role of a supermarket employee trying to keep the store running while dealing with bizarre situations.

## About the Game
**Bizarre Bazaar** is a first-person game set in the fictional city of San Davistan. Players work as supermarket employees, responsible for helping customers, catching shoplifters, and maintaining a good relationship with their boss. Players must manage their time and resources to keep the store profitable and avoid getting fired.

## Gameplay Features
- **Customer Management:** Serve customers and help keep store running.
- **Restocking:** Refill shelves and maintain inventory.
- **Shoplifting Detection:** Watch for suspicious customers and identify thieves.
- **Confrontations:** Decide how to handle shoplifters and suspicious situations.
- **Store Management:** Earn money and maintain store profitability.
- **Boss Trust:** Keep your buss satisfied with performance.
- **Day Progression:** Complete daily shifts and progress in the game.

## Running the Project
1. Download/clone the project repository.
2. Open the Godot Engine.
3. Import by selecting the Bizarre Bazaar project.
4. Open the project in the Godot editor.
5. Run the main game scene and have fun!
